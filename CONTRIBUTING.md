# Contributing to Vidown

Thank you for your interest in contributing to Vidown.

## Current Architecture & Build Status

**IMPORTANT:** The codebase currently operates on a hybrid architecture:

1. **Shipped Production Source (`src/content/`)**:
   - The shipped bundle `content-script.js` (1,954,777 bytes) is generated by `scripts/build_content_script.js`.
   - It reads from the 649 split modules in `src/content/` (mapped via `src/content/module-registry.js` and `src/content/slots.js`), inlines the shared regenerator core (`src/content/vendor/regenerator-core.js`), wraps them into the Webpack IIFE bootstrap (entry module 543), and minifies the output via `esbuild.transformSync`.
   - **This is the only source code that actually executes in the browser.**

2. **Experimental Prototype Layer (`src/experimental/content-next/`)**:
   - An unwired architectural draft (~26 KB across 4 platform families) exploring readable ES modules.
   - It includes:
     - `core/constants.js`: Media types, MIME maps, quality profiles.
     - `core/events.js`: EventBus wrapper.
     - `core/utils.js`: DOM queries, file size formatting, AES link deciphering.
     - `crypto/crypto-rollup.js`: Consolidated CryptoJS loader.
     - `detector/attribute-stamper.js`: Companion attribute reader/stamper.
     - `detector/dom-scanner.js`: MutationObserver element scanner.
     - `providers/`: TikTok, Facebook, YouTube, and HLS/DASH extractors.
     - `index.js`: Draft top-level ES module entry point.
   - **Nothing in the build pipeline or the browser currently loads this layer.** Full semantic reconstruction of the 649 modules into this layer is an active, open research track pending stakeholder direction.

## Testing & Quality Gates

All contributions must pass the automated test suites:

```bash
# Run all 68 automated test suites
npm test

# Run golden characterization tests on real DOM fixtures
node tests/test_golden_behavior.js

# Run vendor deduplication and size gates
node tests/test_milestone_2_dedupe.js

# Build production bundle
npm run build:content

# Package extension zip
npm run package
```

### Constraints & Invariants
- **Zero Regression**: Media detection on TikTok, Facebook Reels, YouTube, and Generic HLS must pass 100%.
- **Bundle & Package Limits**: Release zip `dist/savior-extension-v2.4.65.zip` must remain $\le 1.15\text{ MB}$ with 0 `node_modules` and 0 executables.
- **Target Platform**: Chrome Manifest V3 (`minimum_chrome_version: 116`).
- **Committed Figures**:
  - Shipped built bundle: 1,954,777 bytes (M3 Batch 1; baseline M2: 1,949,390 bytes).
  - Net raw code reduction: 450,148 bytes (Gate 5 target: >= 450,000 bytes).
  - Canonical module 126: 43,355 bytes.
  - Shared regenerator core: 2,564 bytes.
