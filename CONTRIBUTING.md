# Contributing to Vidown

Thank you for your interest in contributing to Vidown.

## Current Architecture & Build Pipeline

All extension runtime scripts (`content-script.js`, `background.js`, `common.js`, and `inject/*`) are compiled from structured, readable sources under `src/` via the unified `npm run build` pipeline:

1. **Modular Content Script (`src/content/`)**:
   - The shipped bundle `content-script.js` (2,352,581 bytes) is generated by `scripts/build_content_script.js`.
   - It compiles 649 structured modules across 776 slots (127 null holes) mapped via `src/content/module-registry.js` and `src/content/slots.js`.
   - Third-party libraries are isolated under `src/content/vendor/` (`cryptojs`, `qrcode`, `stream`, `fast-xml-parser`, `mustache`, `eventemitter3`, `buffer`, `shims`, `parser`, `elliptic`).
   - Project logic is organized semantically into `core/`, `detector/`, `platform/`, `providers/`, and `widget/`.

2. **Modular Background Service Worker (`src/background/`)**:
   - The shipped bundle `background.js` (1,185,532 bytes) is generated by `scripts/build_background.js`.
   - Decomposed into subsystem modules: `entry/`, `messaging/`, `downloads/`, `storage/`, `tabs/`, `events/`, `crypto/`, `utilities/`.

3. **Modular Common Runtime (`src/common/`)**:
   - The shipped bundle `common.js` (501,606 bytes) is generated by `scripts/build_common.js`.
   - Decomposed into `core-utils/`, `entry/`, `crypto/`, and `utilities/`.

4. **Main-World Inject Extractors (`src/inject/` & `inject/`)**:
   - Source main-world site extractors are maintained under `src/inject/` and built to `inject/` via `scripts/build_inject.js`.

## Building from Source

The build pipeline compiles all extension artifacts from unpacked source:

```bash
# Clone repository
git clone https://github.com/DontAskMeWhy0507/Vidown.git
cd Vidown

# Install dependencies
npm install

# Full build: compiles common.js, background.js, content-script.js, inject/, and packages release zip
npm run build

# Development build with unminified output and inline sourcemaps
npm run build:dev
```

## Testing & Quality Gates

All contributions must pass the automated test suites:

```bash
# Run all automated test suites
npm test

# Run golden characterization tests on real DOM fixtures
node tests/test_golden_behavior.js

# Run background and common messaging oracle test
node tests/test_background_common_messaging.js

# Run crypto test vector verification
node tests/test_crypto_consolidation.js

# Run release package cleanliness test
node tests/test_package_release_cleanliness.js
```
